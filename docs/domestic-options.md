# 幻尔与陆吾的替代选择

资料核对日期：2026-11-26。以下是技术选项，不是已经完成采购和迁移的 BOM。

| 选择 | 官方公开配置 | 对 M10 的参考价值 |
| --- | --- | --- |
| 幻尔 WonderDuck | RK3566 + AT32，HX-08LCM 磁编码舵机，标称 0.06 s / 60° | 双足 RL 开发参考；官方介绍 MuJoCo / PPO 路线，软件包范围与交付需确认 |
| 幻尔 HTS-35H | 35 kgf·cm @ 11.1 V，0.18 s / 60°，UART 115200，位置 / 电压 / 温度反馈 | 受力关节台架候选，尚未验证连续扭矩、带载速度与总线时序 |
| 陆吾 XGO-Rider2 | CM5 + ESP32、FOC 无刷轮毂、4.5 kgf·cm 磁编码总线舵机 | 更接近轮足形态；官方提供 LQR / SDK 相关说明，不能据此认定其完整 RL 训练源码已公开 |

当前 M10 优先保留差速底盘完成跟踪闭环。需要轮足验证时参考陆吾，需要双足强化学习开发时参考幻尔。品牌国产替代与芯片国产化分别评估：Rider2 使用树莓派 CM5。

WonderDuck 官网当时标注 12 月 7 日发货。所有标称参数需按电压、负载、温度和测量口径再次核验；不可仅按扭矩数值判定兼容。

来源：[WonderDuck](https://www.hiwonder.com/products/wonderduck)、[HTS-35H](https://www.hiwonder.com/products/hts-35h)、[XGO-Rider2](https://www.xgorobot.com/rider.html)。

## “国产化替代”需要拆成几层

| 层次 | 要回答的问题 | 本次方案的边界 |
| --- | --- | --- |
| 品牌与采购 | 能否获得国内供货、技术支持和备件 | 不等于已验证量产交期与成本 |
| 执行器 | 是否支持所需控制模式、反馈周期和持续负载 | 需要台架，不只看峰值扭矩 |
| 算力与控制芯片 | SoC、MCU 和电机驱动来自哪里 | Rider2 的 CM5 不能归为全国产算力栈 |
| 软件可控 | SDK、固件、训练配置和模型分别开放哪些 | 有 SDK 不等于完整训练链路开源 |

## Beni 舵机如何寻找候选

OpenBeni 披露的是仿真执行器参数，尚不能据此确认量产舵机型号、连续额定力矩和固件接口。替换前应先确定关节需要的是位置、速度还是力矩控制；UART 总线位置舵机不能自动替代具有不同内环和力矩控制语义的执行器。

35 kgf·cm 约等于 3.43 N·m，但单位换算不会让堵转 / 标称力矩变成可持续输出。`0.06 s / 60°` 与 `0.18 s / 60°` 还需核对电压、负载和测试条件，不能据此直接计算整机闭环带宽。

## 选型时要测什么

| 台架项目 | 记录 | 为什么会影响迁移 |
| --- | --- | --- |
| 控制模式与单位 | 位置 / 速度 / 力矩、角度范围、正负号 | 决定动作空间能否表达 |
| 总线时序 | 多关节轮询、命令到生效、反馈周期及抖动 | RL 与控制器需要接近真实的延迟模型 |
| 带载能力 | 持续负载、带载速度、温升和供电电流 | 峰值参数不代表长时间运行能力 |
| 死区与间隙 | 小命令不响应、反向迟滞、重复定位 | 直接影响抖动与跟踪误差 |
| 故障行为 | 丢包、断连、欠压、过温与重启输出 | 决定故障后能否保持可解释状态 |

当前建议仍是：现有差速平台先完成连续跟踪；独立舵机台架可评估幻尔候选；轮足平台参考陆吾；双足 RL 开发参考 WonderDuck。它们是不同层次的选项，不能写成三款完全互换的采购件。没有完成台架和迁移前，不给出“完全兼容”结论。
