# 验证与已知限制

## 历史实机记录

| 项目 | 记录 | 不能据此声称 |
| --- | --- | --- |
| UVC 取流 | 1280×720 MJPEG，约 60 秒 / 1800 帧 | 完整实时视觉闭环已稳定 |
| TFLite | 单次采集 500–600 ms，推理 75–90 ms，抓拍到决策约 600–700 ms | 包含真实电机执行的总延迟 |
| RKNN | SSD Inception v2 INT8，4000 次平均约 147 ms，6.81 FPS | 跟踪 / 叠框 FPS，或相对另一模型的加速比 |
| 底盘 | 握手、ACK、遥测与点动；记录中用户确认轮子动作及左轮修正 | 所有方向物理语义与 30 分钟联合测试均完成 |

## 当前主要限制

- 旧 RKNN Runtime 1.0.0 / Driver 0.4.2 与所尝试的新模型不兼容。
- C++ 决策、Web 联调和 Mac 仿真不等于 Android 常驻实时检测服务。
- 视觉电机后端默认 Mock，尚未与正式 V2 完成统一适配。
- 固定目标、旧框控制隔离、语音 AEC / 打断和 M10 RL 均待验证。
- 历史测试固件、GPIO 映射与现场接线存在演变，必须按当前正式候选重新复核。

本次开源整理的主机测试结果记录在 [HOST_VALIDATION.md](HOST_VALIDATION.md)。主机测试不会替代硬件验收。
