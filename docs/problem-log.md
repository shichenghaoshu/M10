# 问题清单与开发路线

本页区分历史实机记录与静态代码发现。优先级表达开发依赖，不代表问题均在真实底盘触发。依据为 2026-11-26 的公开快照。

2026-11-27 新增 `m10_runtime/`：人工遥控路线已加入 V2 适配、非零动作期限、独立租期与匹配 ACK。下表保留旧模块的问题依据，不表示这些旧工程已被统一替换；新路线的测试与实机边界见 [one-click.md](one-click.md)。

## 硬件反馈与执行问题

| 编号 | 当前事实 | 尚缺什么 |
| --- | --- | --- |
| H01 | 历史连调修正过左轮极性，接线发生过变化 | 每个方向的架空视频、符号和地面低速复核 |
| H02 | 遥测左右值为目标，不是编码器轮速 | 测速、死区、左右速度标定或编码器 PID |
| H03 | STBY 外接高电平，代码 `STBY_PIN=-1` | 核对逻辑供电与电平，不能宣称软件拉低 STBY |
| H04 | 电池 / 障碍为 `0xFFFF`，角度为 0 占位 | 真实采样、有效标志、单位和异常范围 |
| H05 | Linux 以串口可打开为连接依据，无响应也可能返回 `ok: true` | 能力握手、ACK 校验、设备身份和超时状态 |
| H06 | 固件只记住最近一个命令的 type / sequence | 跨消息、序号回绕和重连的去重契约 |

ACK、PWM 目标、轮子转动和准确轮速应分别验收。仅修改串口打印不能证明物理问题已解决。

## 推进顺序与交付物

| 阶段 | 交付物 | 下一阶段前需要的证据 |
| --- | --- | --- |
| 1. 平台与协议 | 系统版本、接线表、V2 适配器和时序表 | 握手、ACK、停止、重连的主机与架空记录 |
| 2. 连续感知 | 常驻帧流、回放、目标锁定 | 时间戳完整，遮挡和旧帧实验可重复 |
| 3. 低速底盘跟随 | 单一仲裁、短期限动作、轮速标定 | 固定目标、丢失停止、轮向和异常恢复 |
| 4. 语音联动 | 一轮对话、表情、TTS 取消 | 首包 / 首声时延、插话和断网实验 |
| 5. 执行器替代 | 候选件台架、供电和通信记录 | 持续负载、发热、反馈周期与断连行为 |
| 6. 形态升级与 RL | 自有仿真、策略和部署适配 | 同任务控制基线比较、配置和模型可追溯 |

当前差速平台不依赖 RL 才能完成目标跟随。先完成可测量的观测、控制和反馈闭环，可以为之后的轮足或双足研究提供基础。

## 每次实验保留什么

建议记录提交 SHA、系统 / SDK / 模型版本、配置哈希、接线版本、输入样例、单调时间戳、命令序号、原始响应、停止原因和必要的视频片段。默认不上传家庭原始录像。

异常记录采用“触发条件 → 预期 → 实际 → 证据 → 修复提交 → 回归结果”。未测项目明确标待测，不以页面变绿或服务启动代替动作验收。
